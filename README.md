# Ignicia Charter — Fleet Booking & Logistics Dispatch

> **Live Portal (Vercel):** [https://ignicia-charter-demo.vercel.app](https://ignicia-charter-demo.vercel.app)  
> **Client:** Ignicia Technologies  
> **Tech Stack:** React, Node.js, WebSockets, Google Maps API

---

## 📌 Project Overview
Ignicia Charter is a full-stack transport logistics platform that automates charter group bookings, real-time driver dispatch notifications, and fleet route management.

---

## 🚀 Key Engineering Highlights
* **Real-Time Driver Notification System:** Instant websocket dispatch alerts for active fleet drivers.
* **Admin Dispatch Console:** Multi-route optimization and live GPS tracking integration.
* **Fleet Route Optimization:** Eliminates single-seat waste and optimizes vehicle utilization.
